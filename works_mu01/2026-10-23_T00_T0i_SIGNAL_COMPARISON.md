# T00 / T0i 原始信号与控制变量比较：重点 C32P23

记录日期：2026-10-23。这里的 CP23 指 C32P23；当前不做方向平均。

## 结论先行

1. **C32P23 的 T0i 在已核对的 pz=2、flow=162 上有明确的原始统计优势。**tsep=8 中点的信噪比为 T0i/T00=8.46/4.73，tsep=12 为3.05/2.03。这些数字直接来自逐jackknife的R，没有借助二态拟合、共享能隙或动力学重标度。
2. **同一T0i在不同源汇间隔上的中点，tsep=7–10目前可以对齐。**保留跨tsep相关性的差值检验，与tsep=8相比均不足0.4个配对标准差。常数诊断得到0.5988±0.0485，Q=0.936；这仅说明这些中点在现有精度下相容，不证明已经去除了激发态。
3. **T00与T0i的裸比值不要求数值相等。**它们有不同的符号、动力学系数和信号幅度。比较统计质量首先看原始gvar和|均值|/误差；检查是否对应同一物理量才需要额外的动力学、匹配和符号约定。
4. **C24P29的结论不能直接套用到C32P23。**同条件C24P29的pz=1、flow=162中点更偏向T00；C32P23的pz=2则偏向T0i。先前将旧T00成品与新T0i直接比较得出的笼统优劣结论，不能用作current的控制变量结论。

### 算法与可复现代码

对N个delete-one jackknife样本 $R^{(b)}$，使用

$$\bar R=\frac1N\sum_b R^{(b)},\qquad \sigma^2_{JK}=\frac{N-1}{N}\sum_b(R^{(b)}-\bar R)^2,\qquad SNR=\frac{|\bar R|}{\sigma_{JK}}.$$

R的最后一轴已经是jackknife样本，不能当作独立组态再套普通标准误，也不能额外除一次sqrt(N)。中点tsep8/12均为偶数，不涉及两个中点合并。

```python
import numpy as np
import gvar as gv
root = '/home/gaomeiqi/T0i_new/sym_1022/analyze_1022'
R03 = np.load(root + '/wide_tsep/C32P23/data/imag/C32P23/T03/Px0Py0Pz2/R_3pt_2pt_C32P23_1p620.npy')[2, 2]
with np.load(root + '/controlled_C32/data/controls_flow162.npz') as z:
    R44 = z['R'][1].real  # 同pz=2的U44诊断，不是旧T00成品
    np.testing.assert_array_equal(z['R'][2].imag, R03)
for ts in (8, 12):
    for label, R in (("T00", R44), ("T0i", R03)):
        x = R[ts - 4, ts // 2, :]
        N = x.size
        error = np.sqrt((N - 1) / N * np.sum((x - x.mean())**2))
        value = gv.gvar(x.mean(), error)
        print(ts, label, value, abs(gv.mean(value)) / gv.sdev(value))
```

若要把一整段tau转换成保留相关性的gvar数组：

```python
samples = R03[8 - 4, :9, :]  # tau=0..8; 最后一轴为JK
mean = samples.mean(axis=1)
delta = samples - mean[:, None]
cov = (samples.shape[1] - 1) / samples.shape[1] * (delta @ delta.T)
print(gv.gvar(mean, cov))
```

因此8.46/4.73来自0.617252/0.073001与1.114494/0.235632；3.05/2.03来自1.189684/0.389747与1.094259/0.539025。负号不降低SNR，SNR取均值绝对值。

## 5. C24P29为什么不同

原来的比较混合了旧T00零动量、tsep上限18、较窄M先验与新T0i的pz=1、上限16、宽M先验；不能把差别唯一归因于current。重新固定pz=1等输入后：

| flow | tsep | C24 T00 SNR | C24 T0i SNR |
|---:|---:|---:|---:|
| 81 | 8 | 13.74 | 11.78 |
| 81 | 12 | 3.90 | 2.29 |
| 162 | 8 | 21.54 | 17.73 |
| 162 | 12 | 7.54 | 4.26 |

C24 flow162、tsep8时，T0i在当前裸量归一化下的绝对误差约为T00的56%，但信号幅度约为46%，所以相对精度没有改善。不同动力学系数的确定性重标度不会改变SNR。C32的T00背景涨落与相关性不同，不能用C24的结论推断C32。
两种current在每个同条件比较中使用完全相同的2pt分母；同动量差别来自插入通道及其与2pt的相关性。分子也含2pt，不能把它全部归为“纯current噪声”；也不能把带协方差的方差项直接解释为独立贡献百分比。

## 6. 动力学一致性：辅助检查，不用于计算上面的SNR

动力学因子是把同一个矩阵元写成不同EMT分量时出现的E、p系数，并非为了让曲线重合而拟合的任意scale。参考连续谱关系OB=4/3 U44、OA3=U34，检查

$$X_{44}=-\frac{2E\,\mathrm{Re}R_{44}}{3E^2+p^2},\qquad X_{34}=\frac{\mathrm{Im}R_{34}}{2p},\qquad p=2\pi n/L.$$

这里明确采用-Re(R44)、+Im(R34)的展示符号。共同整体因子不影响一致性检查；最终Wick旋转与动量傅里叶符号必须按原始生成约定核对。本报告没有靠翻转未知符号或拟合独立比例强制对齐。
E来自相同有序组态2pt的log线性相关拟合t=8..12，逐JK传播；另检查6..10、10..14。C32 flow162得到E约0.687，主能量窗口Q约0.601。动力学检查中同一组态的R44、R34、E相关性均保留。
在上述诊断约定下，C32 flow162、tsep8的X34-X44约为-0.84个配对标准差，tsep10约-0.89个标准差，当前幅值没有显著不相容。它们仍是有限a、有限flow的裸量，不是已完成匹配和重整化的动量分数。

## 7. 当前限制与下一步

- SNR是指定点的统计指标，不是整条三点函数的全局SNR，也不是最终矩阵元的相对误差。
- 先检查未对称平均的tau曲线与配对差值，再检查不同tsep的稳定性；不能因对称后的图更平就确认平台。
- 当前沿用固定全样本减除均值的统计约定，尚未建立最终重采样/自相关/匹配误差预算。
- 当前重点支持C32P23的pz=2。不能推广到pz=4–6；较大动量的2pt已很噪，可能成为瓶颈。
- 数据显示C32的T0i值得继续研究，但是否给出更可靠的最终基态矩阵元，仍需共同的窗口、激发态模型和flow安全距离检查。
