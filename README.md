# Proton Spin and Flow

## Why did I start this project?

The proton spin puzzle is one of the first questions that made me realize how much of hadron structure remains hidden inside QCD.

The more I learned, the more subtle the issue became:

- What exactly is meant by "spin"?
- Which decomposition is physically meaningful?
- What can be calculated on the lattice?
- What role does gradient flow play?

This repository is a record of that exploration.
